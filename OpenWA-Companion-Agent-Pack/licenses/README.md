# Licenses Directory

This pack intentionally does not freeze third-party license texts before the dependency audit.

During Batch 01 the agent must:
1. Pin exact dependency versions/commits.
2. Copy the exact license text supplied by each pinned project into this directory.
3. Preserve copyright notices.
4. Update THIRD_PARTY_NOTICES.md.
5. Reject dependencies with missing/unclear licensing.

Original OpenWA starter assets in this pack are project-owned generic assets and do not contain WhatsApp proprietary artwork.
