# Skill: Licensing & Attribution

Every reused component must have:
- project name
- author/org
- source repository
- exact version/commit
- license
- modifications summary
- whether code is shipped or used only as design reference

Unknown/no-license code: do not ship.

## About screen
Show:
- OpenWA Companion version
- unofficial disclaimer
- repository
- Open Source Components
- Licenses
- Credits

## Files
Maintain:
- THIRD_PARTY_NOTICES.md
- DEPENDENCY_LOCK.md
- DESIGN_REFERENCES.md
- LICENSES directory

Do not imply affiliation with WhatsApp/Meta.
