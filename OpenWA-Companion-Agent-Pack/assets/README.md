# OpenWA Starter Assets

These are starter assets, not WhatsApp assets.

Folders:
- `logo/`: OpenWA Dual Chat Link logo
- `launcher/`: adaptive launcher assets + PNG preview
- `icons/`: generic navigation/action icons
- `illustrations/`: pairing and local-privacy illustrations
- `empty-states/`: empty chat state
- `design_tokens.json`: starter UI tokens

The AI agent should convert SVGs into Android VectorDrawable where useful and create density-specific launcher resources as part of the Android build.
